# Starter Dashboard Documentation

This folder contains product and technical documentation for the Starter Dashboard application.

## What you will find here

- Product-level feature documentation for each app module.
- Technical references for routing, architecture, and shared utilities.
- Contributor guides for adding pages, components, and URL-synced filters.

## Audience

- Product managers and stakeholders evaluating capabilities.
- Frontend developers extending the dashboard.
- Designers and QA engineers validating behavior by module.
